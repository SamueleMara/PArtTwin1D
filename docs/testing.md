# Testing

```bash
conda activate parttwin_sim && cd ~/PArtTwin1D && source scripts/activate_sim.sh
python -m pytest -q                                              # all tests collected; opt-in tiers SKIPPED
PARTTWIN_RUN_GPU_TESTS=1 python -m pytest -v tests/integration   # real ManiSkill/SAPIEN + gsplat CUDA
PARTTWIN_RUN_GUI_TESTS=1 python -m pytest -v tests/gui           # real browser GUI
bash scripts/test_gpu.sh                                         # both tiers, logs in outputs/logs/
```

| Tier | Location | Real or mocked | Requires |
|---|---|---|---|
| unit | `tests/unit/` | real NumPy/Torch math, real PLY I/O, real URDF parsing. `test_coordination.py` uses a **stand-in driver** (threading logic only); `test_splat_link_pose.py::test_sh_directions_are_canonical` **patches** the SH kernel to capture directions | CPU |
| integration | `tests/integration/` | **no mocks**: ManiSkill 3.0.1 / SAPIEN 3.0.3 PhysX (CPU and CUDA, one subprocess per backend), gsplat 1.5.3 CUDA kernels | NVIDIA GPU, `PARTTWIN_RUN_GPU_TESTS=1` |
| gui | `tests/gui/` | **no mocks**: live viser server, pinned nerfview, real gsplat renders, real PhysX, headless **system Google Chrome** driven by Playwright (mouse orbit/pan/zoom, slider typing and dragging, buttons, checkboxes, dropdowns, two clients, reconnect, Ctrl+C) | GPU + Chrome, `PARTTWIN_RUN_GUI_TESTS=1` |

Skipped tests are reported as `SKIPPED`, never as passes.

## Isolation

* `pyproject.toml` blocks ROS Jazzy's pytest plugins by name (`-p no:launch_testing …`)
  so even a bare `python -m pytest` with ROS on `PYTHONPATH` collects cleanly;
  `scripts/activate_sim.sh` additionally unsets `PYTHONPATH` and sets
  `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1`.
* `norecursedirs` excludes `legacy/`, `third_party/`, `outputs/`.
* `tests/unit/test_imports.py` asserts: `parttwin1d` comes from `src/`, no
  `parttwin_smoke`, no Trash paths in `sys.path` or any `direct_url.json`, no eager
  SAPIEN import, and that `pytest --collect-only` from the repo root succeeds.
